# E2E Scenario: TipTap behavior in visual editor

## Purpose

Проверить, что в визуальном редакторе блока `text` и `text_image` на базе TipTap:

- существующий текст подгружается сразу при первом открытии;
- панель форматирования корректно применяет стили;
- каретка не "залипает" в начале строки при наборе;
- после сохранения HTML из TipTap остается в `content.text`.

## Preconditions

- Локальная среда поднята (`make up`).
- Тестовая БД подготовлена (`make test-db`).
- Доступен пользователь с ролью администратора.
- Открыта админка `/admin/content/pages`.

## Steps

1. Открыть страницу, где у блока `text` уже есть сохранённое значение в поле `text`.
2. Открыть модалку редактирования этого блока (первое открытие).
3. Убедиться, что сохранённый текст отображается сразу, без повторного открытия модалки.
4. Поставить фокус в поле `Текст`.
5. Набрать последовательность: `123456789`.
6. Выделить часть текста и нажать `B` (bold).
7. Добавить маркированный список через кнопку `Список`.
8. Добавить ссылку через кнопку `Ссылка`, ввести корректный URL.
9. Не двигая мышь, продолжить ввод: `abc`.
10. Сохранить блок.
11. Открыть режим `JSON` и убедиться, что поле `content.text` содержит HTML с форматированием.
12. Повторить шаги 1-11 для блока `text_image`.

## Expected result

- На первом открытии редактора поле `Текст` уже заполнено сохранённым содержимым.
- Набор идет в стандартном режиме LTR (слева направо).
- Каретка после каждого символа двигается вправо.
- Символы появляются в порядке ввода (`123456789abc`), без реверса (`987...`) и без "прыжков" каретки в начало.
- Форматирование (bold, список, ссылка) видно в редакторе и сохраняется после повторного открытия блока.
- Поле `content.text` в JSON содержит ожидаемый HTML TipTap.

## Regression signal

Сценарий считается проваленным, если наблюдается хотя бы одно:

- каретка остается в начале и не двигается вправо;
- введенные символы визуально "уезжают" вправо при фиксированной каретке;
- текст реверсится (например, `987654321` вместо `123456789`).
- сохранённый текст отсутствует при первом открытии и появляется только после повторного открытия модалки.
- форматирование теряется после сохранения блока или повторного открытия редактора.
