# E2E Scenario: Caret behavior in visual editor

## Purpose

Проверить, что в визуальном редакторе блока `text` и `text_image` каретка не "залипает" в начале строки при наборе текста.

## Preconditions

- Локальная среда поднята (`make up`).
- Тестовая БД подготовлена (`make test-db`).
- Доступен пользователь с ролью администратора.
- Открыта админка `/admin/content/pages`.

## Steps

1. Открыть любую страницу с блоком `text` или создать новый блок `text`.
2. В модальном окне блока переключиться в режим `Визуально`.
3. Поставить фокус в поле `Текст`.
4. Набрать последовательность: `123456789`.
5. Не двигая мышь, продолжить ввод: `abc`.
6. Повторить шаги 1-5 для блока `text_image`.

## Expected result

- Набор идет в стандартном режиме LTR (слева направо).
- Каретка после каждого символа двигается вправо.
- Символы появляются в порядке ввода (`123456789abc`), без реверса (`987...`) и без "прыжков" каретки в начало.

## Regression signal

Сценарий считается проваленным, если наблюдается хотя бы одно:

- каретка остается в начале и не двигается вправо;
- введенные символы визуально "уезжают" вправо при фиксированной каретке;
- текст реверсится (например, `987654321` вместо `123456789`).
