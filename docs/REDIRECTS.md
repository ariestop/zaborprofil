# SEO Redirects

Модуль `Seo\Redirect` отвечает за 301/302/307/308 редиректы до публичного
рендера страниц.

## Возможности

- хранение редиректов в таблице `seo_redirects`;
- быстрый поиск активного редиректа по `source_path`;
- автоматический 301 при изменении `Page.path`;
- счетчик переходов и время последнего использования;
- Admin API `/admin/api/seo/redirects`;
- Vue-страница `/admin/seo/redirects`.

## Исключения

Редирект-подписчик не обрабатывает:

- `/admin`;
- `/build`;
- `/health`;
- `/uploads`;
- Symfony profiler маршруты.

## Автоматические редиректы

Если URL страницы изменился с `/old/` на `/new/`, Doctrine listener создает
активный редирект `/old/ -> /new/` со статусом `301`, если редирект с таким
источником еще не существует.

Это снижает риск потери SEO-трафика при ручном редактировании адресов страниц.
