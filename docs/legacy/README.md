# Legacy layer

Папка `docs/legacy/` хранит служебную информацию о переходе документации к формату `docs/NN-*.md`.

Канонический источник по архитектуре и процессам: только `docs/NN-*.md`.

## Фактическое состояние

- Исторические файлы совместимости сейчас лежат в корне `docs/*.md` (без префикса `NN-`).
- Полная матрица перехода `source -> target NN` и список кандидатов на удаление: [../48-documentation-normalization.md](../48-documentation-normalization.md).

## Правило приоритета

При расхождении между `docs/*.md` и `docs/NN-*.md` приоритет всегда у `docs/NN-*.md`.

## Когда удалять compatibility-документы

Удаление не-`NN` документа допускается только если:

1. Уникальный контент перенесен в соответствующий `docs/NN-*.md`;
2. Ссылки в документации/тикетах/инструкциях переписаны на `NN`-документы;
3. Удаление согласовано отдельным шагом cleanup.
