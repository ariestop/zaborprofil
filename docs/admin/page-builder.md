# Редактор блоков страницы

## Зачем это сделано

Страница собирается из **структурированных блоков**:

- без GrapesJS и без свободной HTML-верстки страницы;
- с управляемым каталогом блоков, у каждого из которых есть оформление на сайте;
- с централизованной backend-валидацией структуры.

## Где находится

Вкладка «Контент» [единого редактора страницы](page-editor.md): `/admin/pages/:id`
(старый URL `/admin/pages/:id/builder` открывает ту же вкладку).

## Рабочее место

Три колонки на широком экране (`xl`, от 1280 px), на узком — переключатель «Структура / Поля / Просмотр».

**Структура** (слева) — блоки страницы в порядке вывода. У каждого блока понятное название, значок и краткое
содержание («4 шага · Замер, Договор…», «Фото не добавлены»). Метки: «ошибка» (не заполнено обязательное поле),
«заготовка» (остался текст-подсказка из шаблона или пустая галерея), «скрыт». Порядок меняется перетаскиванием.
Плашка «Заготовки в N блоках» ведёт к первому такому блоку. Внизу — кнопка «Добавить блок» и чек-лист
«Перед публикацией»: заготовки, описание для поиска, картинка для соцсетей (ссылки ведут на вкладку SEO).

**Предпросмотр** (в центре) — страница «как на сайте», собранная на клиенте из тех же полей, что и Twig-шаблоны
(`workspace/BlockPreview.tsx`). Клик по секции открывает её поля. У выбранной секции — панель действий: выше, ниже,
дублировать, скрыть/показать, удалить; под ней — «Добавить блок после «…»». Переключатель «Как на компьютере /
Как на телефоне». Если на странице нет блока «Форма заявки», внизу показана общая форма, которую сайт выводит сам.

**Поля блока** (справа) — обычная форма вместо JSON: подписи, подсказки, счётчики длины, выбор фото из медиатеки,
списки пунктов с перестановкой, таблица цен с добавлением строк, rich-text через TipTap. Обязательные поля
проверяются сразу (`requiredContentIssues` в `utils/pageBlocks.ts`, те же правила, что у backend-валидатора
`StructuredBlockPayloadValidator`). Там же: «Название в структуре», переключатель «Показывать на сайте»,
«Дублировать», «Сохранить как шаблон секции» (право `pages.manage_templates`) и «Удалить блок».
Удаление можно отменить из уведомления «Отменить».

**Добавить блок** — окно с поиском и группами (Первый экран, Текст, Списки, Фото, Цены и заявки). В каталоге 11 блоков
с готовым оформлением на сайте: Первый экран, Слайдер, Текст, Вопросы и ответы, Преимущества, Этапы работы,
Фотогалерея, Наши работы, Цены, Призыв к действию, Форма заявки. Новый блок вставляется после выбранного
(или в конец) и сразу открывается для заполнения. Оттуда же — «Вставить секцию из шаблона».

## Формы полей

- Для блоков каталога формы описаны вручную: `workspace/field-specs.ts` (`SPECS`).
- Для остальных (legacy и редкие типы) форма строится по содержимому `content` (`inferFields`):
  строки, длинные тексты, флажки, числа, списки объектов и строк. JSON-редактор нужен только разработчику
  (пункт «Режим JSON» в меню шапки).
- Ссылка кнопки выбирается из списка: «К форме заявки на этой странице» (`#lead-form`) или произвольный адрес.

## Названия блоков

`name` блока хранится в `page_blocks.name` и теперь передаётся в `GET/PUT /builder` и `POST /builder/preview`.
Если клиент не прислал имя, backend сохраняет прежнее имя блока того же типа, а для нового блока —
подпись из `BlockSchemaRegistry`. Старые машинные имена вида «hero classic» редактор показывает как название
типа («Первый экран»).

## Публичный рендер

`TwigBlockRenderer` выводит блок шаблоном `templates/public/blocks/{type}.html.twig` (алиасы на legacy-шаблоны
убраны). Шаблоны structured-блоков читают поля редактора: `hero.classic` — заголовок, подзаголовок, текст, кнопку
и фон; `rich-text` — `html`; `price-table` — `columns`/`rows`; `gallery` — `src`/`image`, `alt`, подпись и т. д.
Пустые блоки (галерея без фото, работы без объектов) на сайт не выводятся. Блок «Форма заявки» выводит
общую форму с заголовком из блока; если он есть на странице, нижняя форма не дублируется.

## Ключевые frontend-модули

- `admin/features/page-editor/ContentTab.tsx` — ленивая загрузка рабочего места
- `admin/features/page-editor/workspace/*` — `ContentWorkspace`, `StructurePanel`, `PageCanvas`, `BlockPreview`,
  `BlockInspector`, `BlockFields`, `AddBlockDialog`, `block-kinds.ts` (каталог, названия, сводки, заготовки),
  `field-specs.ts`
- `admin/modules/page-builder/registry/blockRegistry.ts` — схемы и значения по умолчанию
- `admin/modules/page-builder/utils/pageBlocks.ts` — нормализация и валидация
- `admin/modules/page-builder/state/builderStore.ts` — состояние блоков

## Ограничения

- нет `custom html/js` блока;
- предпросмотр в редакторе повторяет вёрстку сайта упрощённо; точный вид — кнопка «Предпросмотр» в шапке.
