# Roadmap

## Этап 1

- Symfony 8 skeleton.
- PHP 8.4 constraint.
- PostgreSQL, Redis, Doctrine, Security.
- PHPUnit, PHPStan, PHP-CS-Fixer, Rector.
- Vite, Tailwind CSS, Vue 3 entrypoint.
- `src/Shared` и `src/Module`.
- `/health` и `/admin/login`.
- GitHub Actions CI.
- Базовая документация.

## Этап 2

Реализовать базовые модули `Shared`, `User`, `Auth`, `Admin` глубже: seed администратора, роли, права, audit hooks.

## Этап 3

Реализовать `Content`, `Page`, `PageBlock` и блочную модель страниц.

## Этап 4

Реализовать публичный Twig renderer страниц и блоков.

## Этапы 5-13

SEO, sitemap, robots, redirects, media, leads, portfolio, settings, menu, audit log, Vue admin UI, тесты, документация и deploy.
