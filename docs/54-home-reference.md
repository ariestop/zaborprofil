# Главная dev2 по макету №3

По прямому указанию владельца от 21.10.2026 главная повторяет предоставленный макет, а не брендбук «Периметр». Оформление изолировано классом `ref-page`. Старые шаблоны внутренних страниц и общие бренд-токены сохранены.

Маршрут `/` обслуживает `HomeDesignController`: это отдельная SSR-страница с фиксированной композицией, не зависящая от наличия главной в новой базе CMS. Существующие CMS-данные не удалены, но блоки CMS на этой главной не выводятся. Перенос редактирования нового макета в CMS — отдельная задача. Главный заголовок — единственный H1.

Все надписи, кнопки, меню и формы — HTML. Из исходного макета берутся только иллюстрации (SVG viewBox для отдельных фотографий из WebP). Фон первого экрана восстановлен встроенным ImageGen из того же макета без надписей. Картинки помечены как визуализации, параметры примера не выдаются за выполненный объект. Растровые файлы находятся в `public_html/img/home-reference/`.

Задание для восстановления фона: извлечь верхнюю фотографию в формате 2,33:1; убрать надписи, логотип, меню и кнопки; сохранить дом, графитовые ворота, каменные столбы, деревья, освещение и композицию. Фотография после восстановления может немного отличаться от исходного растра.

Форма заявки использует существующий `/api/leads`, согласие, защиту от спама и контекст «Хочу похожий». Детали конструкций открываются в нативных dialog с Escape, возвратом фокуса и закрытием по фону. На телефоне — раскрывающееся меню, две колонки карточек и вертикальный блок конструкции. Основной сайт и ветка dev не изменяются.
