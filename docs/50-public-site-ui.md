# Публичный сайт: вёрстка, UX и перенос контента

Документ описывает оформление публичной части (`dev.zaborprofil.ru`, затем production), принятые UX-решения и скрипт переноса контента со старого WordPress-сайта.

## Принципы

- **Mobile-first.** Основной сценарий посетителя — телефон: позвонить или оставить заявку. Всё остальное подчинено этому.
- **SSR + минимум JS.** Страницы рендерит Twig; скрипт сайта (`assets/site/app.ts`) около 9 КБ (4 КБ gzip). Swiper (~100 КБ) подгружается динамически и только если на странице есть слайдер.
- **Без внешних шрифтов и CDN.** Системный стек шрифтов, иконки — встроенный SVG-спрайт (`templates/public/partials/icons.html.twig`).
- **Один CSS-бандл сайта (~11 КБ gzip).** Tailwind для сайта собирается только из `templates/` и `assets/site/` (`assets/site/site.css`), код админки в него не попадает.

## Дизайн-токены

Токены лежат в `assets/shared/styles/theme.css` (общие для сайта и админки). Цвет бренда — зелёный из логотипа (`#43b115`), более тёмные ступени (`brand-700…950`) дают контраст не ниже 4.5:1 с белым текстом. Компонентные классы (`zp-btn`, `zp-card`, `zp-section`, `zp-hero`, …) описаны в `assets/site/site.css`.

Контакты компании (телефон, e-mail, Telegram, 2ГИС) — Twig-глобал `site` в `config/packages/twig.yaml`; они используются в шапке, подвале, мобильной панели связи и блоках.

## Каркас страницы (`templates/base.html.twig`)

| Элемент | Поведение |
| --- | --- |
| Шапка | Липкая. На телефоне: логотип, кнопка-телефон (44×44), бургер. На ПК: меню, телефон, кнопка «Рассчитать стоимость». |
| Мобильное меню | Выпадающая панель, крупные зоны нажатия (≥48 px), закрывается по Esc, по клику на ссылку и при переходе на широкий экран. |
| Панель связи | Фиксированная плашка «Позвонить / Рассчитать» только на телефоне; скрыта, пока на экране первый экран страницы или сама форма заявки. |
| Подвал | Телефон, почта, карта, соцсети, меню `footer`. Якорь `#contacts`. |
| Меню `header` | Если в админке меню ещё пустое, показываются основные разделы (запасной вариант в шаблоне). |

H1 страницы выводится внутри первого блока `hero.classic`/`hero` (тогда это единственный H1); если страница начинается с другого блока, над ним выводится обычный заголовок.

## Блоки

Публичные шаблоны лежат в `templates/public/blocks/`. Устаревшие (legacy) типы рисуются теми же шаблонами, что и структурные аналоги.

| Блок | UX-решение |
| --- | --- |
| `hero.classic` | H1, подзаголовок, список преимуществ (каждая строка поля `text` — пункт), кнопка и телефон. Фото затемнено нейтральным градиентом для читаемости. |
| `portfolio` | Каталог карточек: на телефоне 2 колонки, вся карточка кликабельна. |
| `features` | Короткие пункты — компактные карточки; с текстом — обычные. |
| `pricing` | На телефоне варианты листаются свайпом, на планшете и ПК — сетка. Кнопка «Рассчитать этот вариант» подставляет название варианта в сообщение формы. |
| `price-table` | На телефоне строки превращаются в карточки (подписи берутся из заголовков колонок). |
| `gallery` | Первые N фото (`settings.visible`, по умолчанию 8) видны сразу, остальные раскрывает кнопка; просмотр в `<dialog>` со стрелками и свайпом клавиатуры. Режим `portrait/contain` — для документов и патентов. Без JS видны все фото. |
| `video` | Лёгкая заглушка; плеер (Rutube, VK Видео, YouTube) подключается по нажатию, файлы mp4 — нативный `<video preload="none">`. |
| `faq` | `<details>` + микроразметка FAQPage. |
| `steps` | Нумерованные шаги: на телефоне компактный список, на ПК — колонки. |
| `cta`, `contact-form` | Призыв к действию с телефоном; форма заявки (если она есть среди блоков, нижняя форма страницы не добавляется). |

Форма заявки: поле телефона (`type=tel`, маска `+7 (___) ___-__-__`), понятные подсказки до отправки, блокировка кнопки на время запроса, обработка обрыва сети и ответа 429.

## Перенос контента

Контент главной и `/zabor-jaluzi/` описан в `tools/content/site-content.mjs` (тексты, цены и список фото взяты со старого сайта; новых фактов нет). Загрузка выполняется через административный API — так же, как работает админка:

```bash
ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD='…' \
  node tools/content/push-site-content.mjs \
    --base-url https://dev.zaborprofil.ru \
    --media-dir ./media            # каталог с файлами для ссылок `media:<имя>`
```

Скрипт идемпотентен: картинки сопоставляются по хешу файла, страницы — по пути, меню — по адресу. Флаги `--only home`, `--no-publish`, `--no-menu`, `--dry-run`. Пароль принимается только через окружение. Скрипт не обходит права: нужен пользователь с доступом к страницам, блокам, медиа, SEO и меню.

Тексты можно править в админке после загрузки; повторный запуск скрипта перезапишет блоки страниц тем, что описано в `site-content.mjs`.
